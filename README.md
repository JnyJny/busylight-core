# busylight-core

## This Repository Has Been Archived

This repository is archived as of version 2.2.0 and is no longer maintained.

Development has moved to a monorepo that includes busylight-core as a workspace package alongside the CLI and other tools:

**[github.com/JnyJny/busylight](https://github.com/JnyJny/busylight)**

All new issues, pull requests, and feature development should be directed there.

### Install

The package is still available on PyPI:

```
pip install busylight-core
```
